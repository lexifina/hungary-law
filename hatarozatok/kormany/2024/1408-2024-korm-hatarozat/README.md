# 1408/2024. (XII. 18.) Korm. határozat

a Magyar Nemzeti Társadalmi Felzárkózási Stratégia 2030 végrehajtásának a 2021–2024. évekre szóló kormányzati intézkedési tervéről szóló 1619/2021. (IX. 3.) Korm. határozat és a 2021–2027 programozási időszak kohéziós célú támogatásainak kifizetését lehetővé tevő 4.2 „A nemek közötti egyenlőséget célzó nemzeti stratégiai keret” és a 4.3 „Az oktatási és képzési rendszer minden szintjét felölelő stratégiai szakpolitikai keret” tematikus feljogosító feltételek teljesítését alátámasztó dokumentumokról szóló 1499/2023.
