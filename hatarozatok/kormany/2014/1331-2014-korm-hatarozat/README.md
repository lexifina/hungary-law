# 1331/2014. (VI. 5.) Korm. határozat

Magyarország Kormánya és az Osztrák Szövetségi Kormány között a közös államhatáron lévő határátkelőhelyekről és határátlépési pontokról, valamint a közúti és vízi közlekedésben a határforgalom ellenőrzésében történő együttműködésről szóló Megállapodás szövegének végleges megállapítására adott felhatalmazásról
