# 1083/2005. (VII. 27.) Korm. határozat

a 2006. évi Úszó, Műugró, Szinkronúszó és Nyíltvízi Úszó Európa-bajnokság létesítményfejlesztési programja időszerű kérdéseiről, a folyamatban lévő sportcélú állami fejlesztések megvalósításához kapcsolódó egyes szervezeti feladatok Belügyminisztérium szervezetrendszerébe történő integrálásáról, továbbá az államháztartás egyensúlyi helyzetének javításához szükséges rövid és hosszabb távú intézkedésekről szóló 2050/2004.
