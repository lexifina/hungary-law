# 1253/2026. (VIII. 7.) Korm. határozat

az európai uniós források lehívhatósága érdekében az Integrált Közlekedésfejlesztési Operatív Program Plusz éves fejlesztési keretének megállapításáról szóló 1501/2023. (XI. 16.) Korm. határozat és az Integrált Közlekedésfejlesztési Operatív Program Plusz kiemelt projektjeinek megállapításáról szóló 1042/2024. (III. 4.) Korm. határozat módosításáról, valamint az EuroVelo 6 és EuroVelo 14 kerékpáros útvonalak fejlesztésének egyes kérdéseiről szóló 1172/2025. (V. 26.) Korm. határozat visszavonásáról
