A Kormány 1853/2017. (XI. 15.) Korm. határozata
az Emberi Erőforrás Fejlesztési Operatív Program módosításáról
A Kormány
1. jóváhagyja az Emberi Erőforrás Fejlesztési Operatív Program 2. számú módosítására vonatkozó – az Emberi Erőforrás
Fejlesztési Operatív Program monitoring bizottsága által jóváhagyott – javaslatot (a továbbiakban: javaslat) a részére
benyújtott tervezet szerint,
2. felhívja az emberi erőforrások miniszterét, hogy gondoskodjon a javaslatnak az Európai Bizottsághoz történő
benyújtásáról.
Felelős: emberi erőforrások minisztere
Határidő: e határozat közzétételét követő harminc napon belül
