# Magyar Közlöny

A Magyar Közlöny (Magyarország hivatalos lapja) jogszabályai és más jogi aktusai, ahogy megjelentek:
`<év>/<lapszám>/<nn>-<jogszabály>.md`, lapszámonként egy commit, a megjelenés napján 12:00-kor (Europe/Budapest).

Forrás: magyarkozlony.hu (a hiteles PDF-ek szövegrétege; OCR nélkül). A hirdetmények, pályázatok és
személyügyi közlemények nincsenek benne. A szöveget a PDF-ből nyertük ki; ha számít, a hiteles PDF az irányadó
(minden fájl elején a hivatkozás).

Magyar Közlöny (Hungary's official gazette) instruments as published, one commit per issue, 1998 onwards.
Text taken from the authentic PDFs' text layer (no OCR); the PDF linked at the top of each file is authoritative.
