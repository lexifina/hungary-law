# 49/1979. (XII. 6.) MT rendelet

A Magyar Népköztársaság Kormánya és az Amerikai Egyesült Államok Kormánya között Washingtonban, az 1979. évi február hó 12. napján aláírt, a jövedelemadók területén a kettős adóztatás elkerüléséről és az adóztatás kijátszásának megakadályozásáról szóló egyezmény kihirdetéséről
