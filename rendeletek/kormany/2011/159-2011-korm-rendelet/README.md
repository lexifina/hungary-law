# 159/2011. (VIII. 11.) Korm. rendelet

a honvédelmi szervezetek működésének az államháztartás működési rendjétől eltérő szabályairól szóló 346/2009. (XII. 30.) (I. 26.) HM rendelet hatályon kívül helyezéséről
