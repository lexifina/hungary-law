# 81/2011. (V. 13.) Korm. rendelet

az Egyesült Nemzetek keretében, Palermóban, 2000. december 14-én létrejött, a nemzetközi szervezett bűnözés elleni Egyezménynek a tűzfegyverek, azok részei és alkatrészei, valamint a lőszerek tiltott előállítása és kereskedelme elleni fellépésről szóló, 2001. május 31-én elfogadott Jegyzőkönyve 13. cikk (2) bekezdése szerinti kapcsolattartási pont kijelöléséről
