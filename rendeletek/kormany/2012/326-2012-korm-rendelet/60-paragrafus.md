## 21. Monitoring tevékenység

60. § (1)[^86] A program operátor a támogatott projektek céloknak megfelelő előrehaladását a végrehajtó ügynökség bevonásával folyamatosan nyomon követi.

(2)[^87] A program operátor minden év december 31-ig a végrehajtó ügynökséggel egyeztetve kockázatelemzésen alapuló monitoring tervet készít és tájékoztatásul megküldi a nemzeti szintű szervek részére. A program operátor köteles törekedni a monitoring terv és a 69. § szerinti helyszíni ellenőrzési terv összehangolására. Ösztöndíj program esetén a program operátor nem köteles egyeztetni a monitoring tervet a végrehajtó ügynökséggel.

(3) A monitoring terv a program operátornak a következő évre tervezett monitoring tevékenységét mutatja be, így különösen a tervezett monitoring látogatásokat, illetve a program és a projektek vonatkozásában tervezett egyéb felülvizsgálatokat.

(4) A monitoring terv megvalósításába a program operátor a végrehajtó ügynökséget a program végrehajtási megállapodás alapján bevonhatja.

(5) Kutatási program esetén a program operátor a szabályzatok 12. mellékletének 5. fejezetében foglaltak szerint köteles a monitoring tevékenységet biztosítani.

(6)[^88] A program szintű szervek és a kedvezményezettek tevékenységének nyomon követése érdekében a nemzeti kapcsolattartó is végezhet az ezen alcím szerinti monitoring tevékenységet.

[^86]: A 60. § (1) bekezdése a 35/2016. (II. 29.) Korm. rendelet 24. § (1) bekezdésével megállapított szöveg.
[^87]: A 60. § (2) bekezdése a 35/2016. (II. 29.) Korm. rendelet 24. § (1) bekezdésével megállapított szöveg.
[^88]: A 60. § (6) bekezdését a 35/2016. (II. 29.) Korm. rendelet 24. § (2) bekezdése iktatta be.
