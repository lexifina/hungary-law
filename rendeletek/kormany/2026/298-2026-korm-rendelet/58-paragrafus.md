## 17. Átmeneti rendelkezések

58. §[^5] [Átmeneti szabály]

Az Otthon Start program keretében biztosított FIX 3%-os lakáshitelről szóló 227/2025. (VII. 31.) Korm. rendelet alapján a 2026. november 16. napját megelőzően benyújtott kérelmekre és létrejött jogviszonyokra az Otthon Start program keretében biztosított FIX 3%-os lakáshitelről szóló 227/2025. (VII. 31.) Korm. rendeletnek a 2026. november 15. napján hatályos rendelkezéseit kell alkalmazni az Otthon Start program keretében biztosított FIX 3%-os lakáshitelről szóló 227/2025. (VII. 31.) Korm. rendelet hatályvesztését követően is.

[^5]: Az 58. § a 411/2026. (XI. 3.) Korm. rendelet 5. §-a szerint módosított szöveg.
