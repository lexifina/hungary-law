# 174/2025. (VI. 30.) Korm. rendelet

az Építési és Közlekedési Minisztérium tulajdonosi joggyakorlása alá tartozó, az ÉMI Építésügyi Minőségellenőrző Innovációs Nonprofit Korlátolt Felelősségű Társaság által ellátott építési beruházásokkal kapcsolatos egyes műszaki szolgáltatási feladatok központi költségvetési szerv általi átvételéről, az ezzel kapcsolatos eljárási kérdések rendezéséről, valamint az állami tulajdonban levő ÉMI Nonprofit Kft. állami építési beruházásokkal kapcsolatos egyes műszaki szolgáltatási feladatok elvégzésére vonatkozó kijelöléséről szóló 51/2016.
