# 186/2021. (IV. 21.) Korm. rendelet

az egyes, az egészségügyi katonák és az egészségügyi honvédelmi alkalmazottak jogállására vonatkozó veszélyhelyzeti szabályokról szóló 601/2020. (XII. 18.)
