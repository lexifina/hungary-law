49/D. § (1)[^225] Az ÚMVP (II. NVT) előirányzatok (XIX. fejezet 2. cím 11. alcím 2. jogcímcsoport) vonatkozásában

a)[^226] kötelezettségvállaló: a Program IH vezetője vagy az általa írásban kijelölt személy,

b)[^227] pénzügyi ellenjegyző: a Program IH gazdasági vezetője vagy az általa írásban kijelölt személy,

c)[^228] teljesítés igazoló: a mezőgazdasági és vidékfejlesztési támogatási szerv vezetője vagy az általa írásban kijelölt személy,

d)[^229] érvényesítő: a mezőgazdasági és vidékfejlesztési támogatási szerv pénzügyi igazgatója vagy az általa írásban kijelölt személy,

e)[^230] utalványozó: a mezőgazdasági és vidékfejlesztési támogatási szerv vezetője vagy az általa írásban kijelölt személy.

(2)[^231] Az ÚMVP (II. NVT) előirányzat (XIX. fejezet 2. cím 11. alcím 2. jogcímcsoport 5. jogcím) TS tengelye vonatkozásában

a) kötelezettségvállaló: a Program IH vezetője vagy az általa írásban kijelölt személy,

b)[^232] pénzügyi ellenjegyző: a Program IH gazdasági vezetője vagy az általa írásban kijelölt személy,

c) teljesítés igazoló: a Program IH vezetője vagy az általa írásban kijelölt személy,

d)[^233] érvényesítő: a mezőgazdasági és vidékfejlesztési támogatási szerv pénzügyi igazgatója vagy az általa írásban kijelölt személy,

e)[^234] utalványozó: a mezőgazdasági és vidékfejlesztési támogatási szerv vezetője vagy az általa írásban kijelölt személy.
