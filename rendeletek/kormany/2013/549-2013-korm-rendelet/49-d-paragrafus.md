49/D. § (1)[^213] Az ÚMVP (II. NVT) előirányzatok (XIX. fejezet 2. cím 11. alcím 2. jogcímcsoport) vonatkozásában

a)[^214] kötelezettségvállaló: a Program IH vezetője vagy az általa írásban kijelölt személy,

b)[^215] pénzügyi ellenjegyző: a Program IH gazdasági vezetője vagy az általa írásban kijelölt személy,

c)[^216] teljesítés igazoló: a mezőgazdasági és vidékfejlesztési támogatási szerv vezetője vagy az általa írásban kijelölt személy,

d)[^217] érvényesítő: a mezőgazdasági és vidékfejlesztési támogatási szerv pénzügyi igazgatója vagy az általa írásban kijelölt személy,

e)[^218] utalványozó: a mezőgazdasági és vidékfejlesztési támogatási szerv vezetője vagy az általa írásban kijelölt személy.

(2)[^219] Az ÚMVP (II. NVT) előirányzat (XIX. fejezet 2. cím 11. alcím 2. jogcímcsoport 5. jogcím) TS tengelye vonatkozásában

a) kötelezettségvállaló: a Program IH vezetője vagy az általa írásban kijelölt személy,

b)[^220] pénzügyi ellenjegyző: a Program IH gazdasági vezetője vagy az általa írásban kijelölt személy,

c) teljesítés igazoló: a Program IH vezetője vagy az általa írásban kijelölt személy,

d)[^221] érvényesítő: a mezőgazdasági és vidékfejlesztési támogatási szerv pénzügyi igazgatója vagy az általa írásban kijelölt személy,

e)[^222] utalványozó: a mezőgazdasági és vidékfejlesztési támogatási szerv vezetője vagy az általa írásban kijelölt személy.
