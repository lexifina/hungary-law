## 49/A–49/B. §[^207]

49/C. §[^208] (1)[^209]

(2) Az ÚMVP (II. NVT) Európai Unió felé el nem számolható kiadásai előirányzat (XIX. fejezet 2. cím 14. alcím 3. jogcímcsoport) vonatkozásában

a)[^210] kötelezettségvállaló: a Program irányító hatóság (a továbbiakban: Program IH) vezetője vagy az általa írásban kijelölt személy,

b)[^211] pénzügyi ellenjegyző: a Program IH gazdasági vezetője vagy az általa írásban kijelölt személy,

c) teljesítés igazoló: a Program IH vezetője vagy az általa írásban kijelölt személy,

d)[^212] érvényesítő: a Program IH gazdasági vezetője vagy az általa írásban kijelölt személy,

e) utalványozó: a Program IH vezetője vagy az általa írásban kijelölt személy.
