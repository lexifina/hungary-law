## 49/A–49/B. §[^220]

49/C. §[^221] (1)[^222]

(2) Az ÚMVP (II. NVT) Európai Unió felé el nem számolható kiadásai előirányzat (XIX. fejezet 2. cím 14. alcím 3. jogcímcsoport) vonatkozásában

a)[^223] kötelezettségvállaló: a Program irányító hatóság (a továbbiakban: Program IH) vezetője vagy az általa írásban kijelölt személy,

b)[^224] pénzügyi ellenjegyző: a Program IH gazdasági vezetője vagy az általa írásban kijelölt személy,

c) teljesítés igazoló: a Program IH vezetője vagy az általa írásban kijelölt személy,

d)[^225] érvényesítő: a Program IH gazdasági vezetője vagy az általa írásban kijelölt személy,

e) utalványozó: a Program IH vezetője vagy az általa írásban kijelölt személy.
