## A földgázelosztók közötti kiegyenlítő fizetéseket a következő képletek szerint kell meghatározni:

## KFe = TÁe - KIÁe

| ahol: |  |

| KFe: | az adott földgázelosztóra vonatkozó kiegyenlítő fizetés összege, |

| TÁe: | az adott földgázelosztó árbevétele, amelyet a 2009. évi elosztott mennyiséggel és a naturália adatokkal kell kiszámítani, |

| KIÁe: | az adott földgázelosztónak a 49. § (2) bekezdés a) pontja szerinti indokolt korrigált árbevétel-igénye. |

| ahol: |  |

| IÁe: | a földgázelosztónak a 49. § (2) bekezdés b) pontja szerinti indokolt, a 2009. évi földgázelosztási díjak változását is figyelembe vevő árbevétel-igénye, |

| i: | a földgázelosztói index. |

## IÁe = Áe + EKe

| ahol: |  |

| Áe: | a 2009. évet érintő gázévekre indexált árbevétel igényeknek az iparági átlagos elszámolási különbözet mértékével számított költséggel csökkentett értéke, |

| EKe: | szakértő által, adott földgázelosztóra meghatározott elszámolási különbözet mértékével számított költség-igény. |
