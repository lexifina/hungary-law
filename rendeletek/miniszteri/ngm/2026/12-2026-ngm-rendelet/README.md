# 12/2026. (II. 26.) NGM rendelet

a Dialízis Eszközkezelő Korlátolt Felelősségű Társaság tulajdonosi joggyakorlójának kijelölése, továbbá egyes állami tulajdonú gazdasági társaságokat érintő változások átvezetése érdekében az egyes állami tulajdonban álló gazdasági társaságok felett az államot megillető tulajdonosi jogok és kötelezettségek összességét gyakorló személyek kijelöléséről szóló 1/2022.
