# 60/2009. (XI. 19.) IRM rendelet

a büntetés-végrehajtási szervek működésével összefüggő intézkedésekről és a büntetés-végrehajtási intézetek kijelöléséről szóló 21/1994. (XII. 30.) IM rendelet, a fogvatartottak egészségügyi ellátásáról szóló 5/1998. (III. 6.) IM rendelet, valamint a nemdohányzók védelméről és a dohánytermékek fogyasztásának, forgalmazásának szabályairól a büntetés-végrehajtási szervezetnél szóló 17/1999. (XI. 18.)
